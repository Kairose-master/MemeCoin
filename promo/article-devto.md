# Draft: Why call a security museum SCAM?

## A name with a boundary

SCAM is short for Smart Contract Attack Museum. It is wordplay for an educational archive, not a promise that a token catches scams. The site explains common contract failure patterns and invites research submissions for manual review.

## Patterns, not verdicts

Reentrancy, missing authorization checks, unsafe arithmetic, manipulable oracles, unsafe delegate calls, weak randomness, and unprotected initialization are useful topics for defensive education. A pattern summary is not evidence against a named live project. A suspected issue needs code, assumptions, and a safe reproduction before reviewers can assess it.

## Safe research

Reproductions should run locally or on explicitly authorized test systems. The project does not currently provide a live scanner, confidential vulnerability intake channel, or active bounty. Do not attack live contracts or publish weaponizable details about an unpatched issue in a public report.

## The token is separate from the research

SCAM is a Pump.fun meme token with no intrinsic value or promised returns. The initial launch buy was burned; the creator may hold tokens acquired separately. These facts should be rechecked against on-chain records before publication.
