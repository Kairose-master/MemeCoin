# Public disclosure copy

SCAM is a meme token associated with the Smart Contract Attack Museum, an educational archive of smart-contract attack patterns. The project does not automatically detect live scams, audit or certify deployed contracts, or guarantee any outcome. SCAM has no intrinsic value or promised returns and can lose all value. The creator's initial launch buy was burned; the creator may hold tokens acquired separately. Verify current balances on-chain. No active bounty or operational creator-fee allocation program is currently represented as available.
