# Security reporting policy

## Current disclosure channel

This repository is public and accepts general research candidates and project corrections through GitHub issues. It does not currently provide a confidential vulnerability reporting channel.

Do not submit weaponizable details about an unpatched vulnerability in a public issue, social post, or chat. Do not probe or exploit systems without explicit authorization. If a deployed third-party system may be affected, use that system's established security contact or vulnerability disclosure program.

## What this project accepts

The GitHub issue templates may be used for educational contract candidates, local/testnet demonstrations, and website or archive corrections. Maintainers review submissions manually. Filing an issue does not imply acceptance, an audit, a public finding, or a bounty payment.

Never submit private keys, seed phrases, passwords, API keys, personal data, or information you are not authorized to share.
