# 바운티 규칙 — 멀쩡한 타깃 5개를 깨라

대상: SafeVault · BoundedOwner · LibraryVault · CommitLottery · GuardedInitializer (박물관 "NOT PROVEN" 전시물)

- 제출물: 하네스 `_prove()` 를 통과하는 `Exploit.sol` + 재현 절차
- 지급: SOL, 수수료 풀에서. 풀이 0이면 발행자 시드 0.5 SOL. 타깃당 첫 통과 1건
- **참가에 SCAM 보유 불필요** — 보유가 조건이면 "투자→보상" 구조가 된다
- 공개 채널(텔레그램 공지)에 지급 내역 게시
- 격리된 로컬 EVM 에서만. 실제 배포된 컨트랙트 공격은 범위 밖이고 금지
