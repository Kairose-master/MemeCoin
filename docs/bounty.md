# Research bounty status

**Status: not active and not funded.** No bounty amounts, rewards, or payment timing are currently promised. Do not submit work expecting compensation.

A future program should only be announced after maintainers publish all of the following:

- A funded, publicly verifiable bounty wallet and opening balance.
- Eligible targets, scope, out-of-scope assets, and responsible disclosure rules.
- Reproduction harness, acceptance criteria, severity rubric, and review process.
- Maximum award per finding, payment currency, timing, and dispute process.
- Public receipts for all deposits and payouts, plus a periodic balance reconciliation.

Any future proof of concept must run in an isolated local or explicitly authorized test environment. Attacking deployed contracts, users, or infrastructure is prohibited. Holding SCAM must not be required to report or receive a security bounty.

Until a confidential reporting channel exists, do not place weaponizable details about an unpatched live vulnerability in a public GitHub issue. Use a vendor's established security contact instead.
